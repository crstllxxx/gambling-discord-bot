# Discord Card Games Bot (Python)

Мини-бот для Discord на `discord.py` с двумя мини-играми (блэкджек и рулетка) и общей внутриигровой валютой.

## Что реализовано

- Slash-команды `/blackjack` и `/roulette`
- Интерактивная игра в блэкджек кнопками `Взять` и `Стоп`
- Рулетка: ставки на `красное`, `чёрное`, `зелёное` или конкретное `число` (0–36)
- Экономика с автосозданием баланса (старт — 1000 денег)
- Команды `/balance`, `/leaderboard`, `/pay`, `/grant` и ежедневный бонус `/daily`
- Проверка, что кнопки может нажимать только автор игры
- Автоматическое завершение игры по таймауту
- Логирование и обработка ошибок
- Безопасная загрузка токена из переменных окружения

## Требования

- Python `3.10+`
- Токен Discord-бота

## Быстрый запуск (Windows PowerShell)

1. Создай и активируй виртуальное окружение:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

1. Установи зависимости:

```powershell
py -3 -m pip install -U pip
py -3 -m pip install -r requirements.txt
```

1. Создай `.env` из шаблона `.env.example` и укажи токен:

```env
DISCORD_BOT_TOKEN=твой_токен_бота
```

1. Запусти бота:

```powershell
py -3 bot.py
```

## Настройка Discord Developer Portal

1. Создай приложение и бота.
1. Скопируй токен в `.env`.
1. В `OAuth2 > URL Generator` отметь:
   - `bot`
1. Дай боту права минимум:
   - `Send Messages`
   - `Use Application Commands`
   - `Read Message History` (опционально)
1. Пригласи бота на сервер по сгенерированной ссылке.

## Использование

- В любом канале введи `/blackjack`
- Нажимай `Взять` (взять карту) или `Стоп` (остановиться)
- После завершения раунда кнопки блокируются
- Для рулетки введи `/roulette` и укажи ставку и выбор (цвет или число)
- Проверить баланс: `/balance`
- Узнать топ по монетам: `/leaderboard`
- Перевести монеты игроку: `/pay`
- Админское начисление себе: `/grant` (требует `DISCORD_ADMIN_IDS`)
- Ежедневный бонус: `/daily`

## Файлы проекта

- `bot.py` — основной код Discord-бота, логика игр и экономики
- `requirements.txt` — зависимости Python
- `.gitignore` — исключения для Git
- `data/balances.json` — файл с балансами пользователей (создаётся автоматически, в git не попадает)
- Переменная `DISCORD_ADMIN_IDS` (через запятую) задаёт пользователей с доступом к `/grant`
