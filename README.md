# Discord Gambling Games Bot (Python)

бот для Discord на `discord.py` с играми (блэкджек, crash, слоты, гонки) и общей внутриигровой валютой.

## Что реализовано

- Slash-команды `/blackjack`, `/crash`, `/slots`, `/formula1`, `/totals_list`, `/farm_status`, `/help`
- Интерактивная игра в блэкджек кнопками `Взять` и `Стоп`
- Игра Crash с растущим множителем — успей забрать до краша!
- Слоты — вращай барабаны, три одинаковых символа = выигрыш (до 10x)!
- Формула 1 — делайте ставки на гонщиков и наблюдайте за гонкой в реальном времени!
- Тотализатор — делайте ставки на события сервера!
- Фарм за сообщения — получайте деньги за активность в чате!
- Экономика с автосозданием баланса (старт — 1000 монет)
- Команды `/balance`, `/leaderboard`, `/pay`, `/grant` и ежедневный бонус `/daily`
- Лотерея с розыгрышем джекпота
- Магазин: `/shop` и `/buy` — покупка ролей, эмодзи, смена ника/аватарки, мут друга
- Админские команды для управления заявками, лотереей, тотализатором и фармом
- Проверка, что кнопки может нажимать только автор игры
- Автоматическое завершение игры по таймауту
- Логирование и обработка ошибок
- Безопасная загрузка токена из переменных окружения

## Требования

- Python `3.10+`
- Токен Discord-бота

## Быстрый запуск (Windows PowerShell)

1. Создай и активируй виртуальное окружение:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

1. Установи зависимости:

```powershell
py -3 -m pip install -U pip
py -3 -m pip install -r requirements.txt
```

1. Создай `.env` из шаблона `.env.example` и укажи токен:

```env
DISCORD_BOT_TOKEN=твой_токен_бота
```

1. Запусти бота:

```powershell
py -3 bot.py
```

## Настройка Discord Developer Portal

1. Создай приложение и бота.
1. Скопируй токен в `.env`.
1. В `OAuth2 > URL Generator` отметь:
   - `bot`
   - `applications.commands`
1. Дай боту права минимум:
   - `Send Messages`
   - `Use Application Commands`
   - `Read Message History` (опционально)
1. Пригласи бота на сервер по сгенерированной ссылке.

## Тотализатор (ставки на события сервера)

**Для всех:**

- `/totals_list` — список активных событий для ставок
- `/totals_bet event_id option amount` — сделать ставку на событие
  - `event_id` — ID события (узнать в `/totals_list`)
  - `option` — номер варианта (1, 2, 3...)
  - `amount` — сумма ставки (от 100 до 10000)
- `/totals_status event_id` — статус события и текущие ставки

**Для администраторов:**

- `/totals_create title description options` — создать событие
  - `title` — название (например: "Кто победит в ивенте?")
  - `description` — описание
  - `options` — варианты через запятую: `Команда А, Команда Б, Ничья`
  - `min_bet` — минимальная ставка (по умолчанию 100)
  - `max_bet` — максимальная ставка (по умолчанию 10000)
- `/totals_close event_id winning_option` — закрыть событие и выплатить выигрыши
- `/totals_cancel event_id` — отменить событие и вернуть все ставки

**Пример использования:**

```text
# Админ создаёт событие
/totals_create title:"Кто победит в завтрашнем турнире?" description:"Ставки принимаются до завтра" options:"Красные, Синие, Зелёные"

# Пользователи делают ставки
/totals_bet event_id:1 option:2 amount:500

# После события админ закрывает и определяет победителей
/totals_close event_id:1 winning_option:2
```

**Система выплат:**

- Все ставки формируют общий пул
- Победители (кто угадал правильный вариант) делят пул пропорционально своим ставкам
- Комиссия: 10% (идёт в банк бота)

## Фарм за сообщения 💬

Зарабатывайте деньги, просто общаясь в чате!

**Как работает:**

1. Администратор устанавливает канал для фарма: `/set_farm_channel #канал`
2. Пишите сообщения в этом канале
3. За каждые **30 сообщений** получайте **5 рублей**!

**Команды:**

- `/farm_status` — проверьте, сколько сообщений осталось до награды
- `/set_farm_channel` — (админ) выбрать канал для фарма
- `/reset_farm_counters` — (админ) сбросить все счётчики

**Настройки в `bot.py`:**
- `reaction_triggers` — словарь триггеров и реакций
- `reaction_cooldown` — кулдаун между реакциями на одного пользователя (по умолчанию 5 секунд)
- `reaction_chance` — шанс поставить реакцию (0.0 - 1.0, где 1.0 = 100%, по умолчанию 0.3 = 30%)
